## Reproduction environment

`node scripts/check-unix-bash.cjs` runs safe cases in a disposable **Linux** container, no network, read-only root filesystem, unprivileged user, dropped capabilities, bounded memory/process count and tmpfs scratch space. It compares separately authored stdout, stderr and exit-status expectations and runs `bash -n` on every case and every Bash lesson code fence. It never runs arbitrary learner input.

Image: `debian:bookworm-slim@sha256:7ff6ba31527b9e336162fa061746c366c4b2032f4d2cff2078bea43f78efe3f8`. Bash5.2.15, GNU sed4.9, GNU grep3.8, coreutils9.1, mawk1.3.4. LC_ALL=C, no startup files/BASH_ENV, default IFS, explicit lastpipe/pipefail/errexit/jobcontrol off unless a case enables it. No Bash NUL storage or locale-sensitive Unicode assumptions. Docker is an optional developer verification tool, not a website dependency. `STUDY_UNIX_BASH=...` can select native Linux Bash with the same utilities; report version differences.

## Independent oracles

`scripts/unix-verification.json` contains explicit expected outputs for300 automatic questions. They are written before execution and not generated by querying Bash. `scripts/check-unix.cjs` links every key to its exact displayed program/reference and checks numeric/choice interpretation. `scripts/check-unix-math.py` uses Fraction/integer oracles for statistics, grade boundaries, factorial, primes, temperature and decimal/integer differences, independently of the Bash/awk implementation.

Execution/source/rubric totals and final results are recorded in [QA](unix-final-qa.md). Passing code tests does not certify untested interactive job control, every Unix implementation, root/ACL permission behavior, arbitrary untrusted arithmetic input or an official exam syllabus.
