## วิธีเพิ่มวิชา

1. คัดลอกโฟลเดอร์แม่แบบนี้ไปไว้ที่ `courses/รหัสวิชา/`
2. แก้ชื่อและรหัสวิชาใน `README.md` และ `course.json`
3. เพิ่มวิชาลง `catalog.json` และสร้างหน้าเว็บคลังใหม่
