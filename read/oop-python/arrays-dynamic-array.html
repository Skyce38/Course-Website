Week7 pp.26–38:array มีช่องตำแหน่งต่อเนื่องในแบบจำลอง จึงคำนวณ base_address+i×element_size ได้โดยไม่เดินผ่านสมาชิกก่อนหน้า เป็นเหตุผลของ indexaccessO(1)เมื่อขนาดช่องคงที่
