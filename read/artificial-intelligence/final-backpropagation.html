FINAL: Multilayer Networks และ Backpropagation

S10 Final/ANN.pdf physical pp.19–24 และ S11 Final/Intro_DeepLearning_Slides.pdf pp.2–5 สูตรและภาพตรวจโดยตรง ตัวอย่าง gradient เชิงตัวเลข/แบบฝึกเป็นงานผู้เขียน ไม่ใช่เฉลยอาจารย์ บทนี้เป็น FINAL ในลำดับเผยแพร่ชั่วคราว

เป้าหมายการเรียนรู้

  • อธิบายเหตุผลที่ต้องมี hidden layer และ nonlinear activation
  • คำนวณ feedforward, sigmoid derivative, loss และ backpropagation
  • แยก gradient sign ออกจาก error delta พร้อมปรับ bias/weights ในลำดับถูกต้อง
  • ตรวจผลด้วย finite differences และรู้ข้อจำกัดของการลด loss หนึ่งก้าว

Single Layer สู่ Multilayer

S10 pp.19–21 ต่อจากข้อจำกัด XOR: perceptron เดียวสร้าง linear decision surface เครือข่ายหลายชั้นรวมขอบเขตได้ซับซ้อนขึ้น

S11 pp.2–5 แสดง weighted sum, nonlinear activation และ hidden layers ถ้าทุกชั้นเป็น affine map โดยไม่มี nonlinearity การซ้อนยังยุบเป็น affine map เดียว จึงไม่แก้ XOR ด้วยการเพิ่มชั้นเชิงเส้นอย่างเดียว

XOR ตาม weights ใน S10 p.20

ภาพใช้ binary threshold ไม่ใช่ sigmoid: hidden ตัวบน weights(1,1),bias−.5 ทำ OR; ตัวล่าง weights(1,1),bias−1.5 ทำ AND; output weights(1,−2),bias−.5 บทนี้กำหนด >0 (ไม่มีกรณีเท่าศูนย์สำหรับสี่ inputs นี้)

x1,x2z OR → h1z AND → h2z output → y
0,0−.5 → 0−1.5 → 0−.5 → 0
0,1.5 → 1−.5 → 0.5 → 1
1,0.5 → 1−.5 → 0.5 → 1
1,11.5 → 1.5 → 1−1.5 → 0

นี่เป็นการตรวจ network ที่กำหนดแล้ว ไม่ใช่ผล train ด้วย backpropagation Threshold ไม่ differentiable ที่ 0 และอนุพันธ์ 0 เกือบทุกจุด จึงใช้ smooth sigmoid ในบทเรียน gradient ถัดไป ห้ามแทน threshold ด้วย sigmoid โดยใช้ weights เดิมแล้วอ้าง output XOR เหมือนกัน

ข้อผิดพลาดที่พบบ่อย

  • ผสมδ=(t−y) กับ update ลบจนกลับทิศ หรือใช้ MSE loss แต่ขาดตัวคูณที่นิยามไว้
  • ลืม sigmoid derivative หรือ bias; ใช้ outputweight ใหม่หา hiddenerror
  • คิดว่า hidden target ต้องมี label แยก: error ส่งผ่าน chain rule ได้
  • อ้าง XORthreshold network เป็นผล train sigmoid หรือหยุดเมื่อ sample เดียวถูก
  • สรุป gradient descent รับประกัน global optimum

สรุปเตรียม FINAL

Forward จาก weights เก่า → กำหนด loss → outputgradient → hiddengradient จาก weights เก่า → เก็บทุก gradient → updateweights และ bias พร้อมกัน → ตรวจ loss ใหม่ Backprop คือ chain rule; optimizer คือวิธีนำ gradient ไป update สองขั้นนี้ไม่ใช่คำเดียวกัน
