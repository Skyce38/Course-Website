เป้าหมายการเรียนรู้

  • คำนวณระยะ จัดกลุ่ม และปรับจุดศูนย์กลาง (centroid) ได้ทุก iteration
  • แยก centroid เริ่มต้นออกจาก centroid หลังอัปเดต และตรวจการหยุด
  • คำนวณ SSE และอธิบาย Elbow โดยไม่สรุปว่ามี k ที่ถูกเสมอ
  • แยกข้อมูล X05 ออกจาก A02 และตระหนักถึงผลของสเกล/ค่าเริ่มต้น

แนวคิดและขั้นตอน K-Means

S09 pp.31–34: K-Means เป็น unsupervised learning ที่แบ่งข้อมูลเชิงตัวเลขเป็น k กลุ่ม แต่ละกลุ่มแทนด้วยค่าเฉลี่ย

ไม่ใช้ label เฉลยเหมือน classification กำหนด k และเลือกศูนย์กลางเริ่มต้น จากนั้น (1) assign แต่ละจุดให้ศูนย์กลางที่ใกล้ที่สุด (2) update ศูนย์กลางด้วยค่าเฉลี่ยสมาชิก ทำซ้ำจนศูนย์กลางไม่เปลี่ยนหรือถึงเกณฑ์หยุดที่ประกาศ

ใช้ d² จัดอันดับได้เหมือน Euclidean d=√d² เพราะรากที่สองเพิ่มตามค่า บทนี้ tie เลือกหมายเลข cluster ต่ำสุด; ถ้ากลุ่มว่างคง centroid เดิม นี่เป็นนโยบายผู้เขียน ไม่ใช่กฎเฉพาะจาก source โค้ดใช้เศษส่วนแม่นตรงและ iteration cap; การชน cap ไม่ได้แปลว่าลู่เข้า

SSE=∑j=1k∑i∈Cj∥xi−μj∥22SSE=\sum_{j=1}^k\sum_{i\in C_j}\lVert x_i-\mu_j\rVert_2^2SSE=j=1∑k​i∈Cj​∑​∥xi​−μj​∥22​

SSE ต่ำแปลว่ากระชับตาม features/สเกลที่เลือก ไม่ใช่ classification accuracy การ assign และ update ทำให้ objective ไม่เพิ่มเมื่อใช้นโยบายนี้ แต่รับรองเพียงจุดคงตัว ไม่ใช่ global optimum ภาพ S09 pp.35–40 แสดงขั้นตอนและ objective เชิงเรขาคณิต ไม่ได้แจกพิกัดครบสำหรับจำลองตัวเลข จึงไม่เดาพิกัดจากภาพ

เลือก k และ Elbow

S09 pp.41–45 แสดง objective k=1:873.0, k=2:173.1, k=3:133.6 และชี้ elbow แถว 2 ตัวเลขนี้เป็นค่ารายงานในสไลด์ซึ่งไม่ได้แจกพิกัดครบ ไม่ใช่ SSE ของ A02 หรือ X05 และไม่อ้างว่าคำนวณซ้ำตัวเลขนี้ได้จากภาพ

การลด 699.9 แล้ว 39.5 ชี้ผลตอบแทนลดลง แต่ elbow เป็น heuristic ไม่รับรองมีมุมชัดหรือ k จริง การเพิ่ม k ลด optimum SSE ได้เสมอในนิยาม optimum แต่การรัน local initialization คนละครั้งอาจไม่เรียงสวย ต้องลองหลาย seeds และใช้เหตุผลของงานร่วมกัน k=n อาจ SSE0 แต่ไม่ใช่คำตอบที่มีประโยชน์เสมอ

Python: ติดตามทุกขั้นแบบกำหนดซ้ำได้

โค้ดเสริมไม่พึ่ง sklearn และไม่รันโดยหน้าเว็บ คืน trace ที่ใช้สร้างตาราง ไม่ normalize โดยอัตโนมัติ

Python
1from fractions import Fraction as F234def kmeans_trace(points, centers, max_iter=100):5    points = [tuple(F(str(v)) for v in point) for point in points]6    centers = [tuple(F(str(v)) for v in center) for center in centers]7    if not points or not centers or any(len(p)!=len(centers[0]) for p in points+centers):8        raise ValueError('Nonempty matching dimensions required')9    trace = []10    for iteration in range(1,max_iter+1):11        distances = [[sum((x-y)**2 for x,y in zip(point,center)) for center in centers] for point in points]12        labels = [min(range(len(centers)),key=lambda j:(ds[j],j)) for ds in distances]13        updated = []14        for j,old in enumerate(centers):15            members = [p for p,label in zip(points,labels) if label==j]16            # Authored empty-cluster policy: retain its old center17            updated.append(tuple(sum(p[d] for p in members)/len(members) for d in range(len(old))) if members else old)18        sse = sum(sum((x-y)**2 for x,y in zip(point,updated[label])) for point,label in zip(points,labels))19        trace.append((iteration,centers,distances,labels,updated,sse))20        if updated == centers:21            return trace22        centers = updated23    raise RuntimeError('Iteration cap reached; no convergence claim')242526# A02: Internet (GB), Call (minutes); P01/P02/P03 are initial centers27customers = [(5,100),(45,50),(25,500),(10,200),(50,150),(30,600),(15,50),(55,100),(35,450),(20,150),(60,200),(40,550),(15,250),(40,200),(20,600)]28# X05: different data, with centers from B1:C329workbook_points = [(2,10),(2,5),(8,4),(5,8),(7,5),(6,4),(1,2),(4,9)]30for name,points,centers in [('A02',customers,customers[:3]),('X05',workbook_points,[(2,10),(5,8),(1,2)])]:31    for iteration,old,distances,labels,updated,sse in kmeans_trace(points,centers):32        print(name,iteration,'clusters',[[i+1 for i,c in enumerate(labels) if c==j] for j in range(3)],'centers',updated,'SSE',float(sse))

ข้อผิดพลาดที่พบบ่อย

  • เอา centroid ใหม่มาใช้กับบางจุดภายใน assign รอบเดิม: ต้อง assign ทุกจุดจากชุดศูนย์กลางเดิมก่อน
  • เฉลี่ยระยะแทนเฉลี่ยพิกัด หรือใช้ SSE จากคนละขั้นโดยไม่บอก
  • หยุดหลังรอบแรกโดยไม่ตรวจซ้ำ; เก็บสมาชิกแต่ไม่ตรวจศูนย์กลาง
  • เทียบ SSE ข้าม dataset/หน่วย หรือถือ cluster ID เป็น class จริง
  • สรุป elbow=คำตอบข้อสอบแน่นอนหรือ K-Means หา global optimum เสมอ

สรุปเตรียม FINAL
