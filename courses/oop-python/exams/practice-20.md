# ข้อฝึกปรนัย Python 20 ข้อ

## แนวข้อสอบปรนัย 20 ข้อ

ลองทำก่อนดูเฉลย แต่ละข้อมีคำตอบที่ถูกต้องที่สุดหนึ่งข้อ

### ข้อ 1

Singly Linked List มี `tail` อยู่แล้ว การเพิ่มท้ายมีเวลาเท่าใด?

- ก. O(1)
- ข. O(log n)
- ค. O(n)
- ง. O(n²)

### ข้อ 2

ทำไมการลบตัวท้ายของ Singly Linked List ยังเป็น O(n)?

- ก. ต้องเรียงข้อมูล
- ข. ต้องหา Node ก่อนท้าย
- ค. ต้อง copy ทุก Node
- ง. ต้องทำ rehash

### ข้อ 3

แทรก `new` หลัง `current` โดยรักษา Node ถัดไปเดิมไว้ ควรทำข้อใดก่อน?

- ก. `current = new`
- ข. `current.next = new`
- ค. `new.next = current.next`
- ง. `head = None`

### ข้อ 4

ลบสมาชิกตัวเดียวที่เหลือใน Linked List แล้ว ข้อใดถูก?

- ก. เปลี่ยนเฉพาะ tail
- ข. ไม่ต้องเปลี่ยนอะไร
- ค. เพิ่ม size
- ง. head และ tail เป็น None

### ข้อ 5

Stack เริ่มว่าง ได้รับ `push(1), push(2), pop(), push(3)` แล้ว `peek()` ได้อะไร?

- ก. 1
- ข. 2
- ค. 3
- ง. Stack ว่าง

### ข้อ 6

ข้อใดมีวงเล็บถูกต้อง?

- ก. `([)]`
- ข. `([])`
- ค. `(()`
- ง. `)(`

### ข้อ 7

Undo แล้วพิมพ์ข้อความใหม่ ควรทำอย่างไรกับ redo_stack?

- ก. ล้างทิ้ง
- ข. เรียงข้อมูล
- ค. ย้ายทั้งหมดลง undo_stack
- ง. เก็บเหมือนเดิม

### ข้อ 8

Queue เริ่มว่าง ได้รับ `enqueue("A"), enqueue("B"), dequeue(), enqueue("C")` แล้วตัวหน้าคืออะไร?

- ก. A
- ข. C
- ค. ว่าง
- ง. B

### ข้อ 9

Circular Queue มี capacity = 5, rear = 4 ถ้า enqueue สำเร็จหนึ่งครั้ง rear ใหม่คืออะไร ตามสูตรในบทเรียน?

- ก. 5
- ข. 0
- ค. 1
- ง. 4

### ข้อ 10

Circular Queue ที่ใช้ size ตรวจว่าเต็มด้วยเงื่อนไขใด?

- ก. `front == rear` เสมอ
- ข. `rear == 0`
- ค. `size == capacity`
- ง. `size == 0`

### ข้อ 11

ใน min-heap มี `(2,0,"A"), (1,1,"B"), (1,2,"C")` ลำดับนำข้อมูลออกคืออะไร?

- ก. B, C, A
- ข. A, B, C
- ค. C, B, A
- ง. B, A, C

### ข้อ 12

Bubble Sort เรียงน้อยไปมาก วิ่งซ้ายไปขวาหนึ่ง pass บน `[4,2,3,1]` ได้อะไร?

- ก. `[1,2,3,4]`
- ข. `[2,4,3,1]`
- ค. `[1,4,2,3]`
- ง. `[2,3,1,4]`

### ข้อ 13

Selection Sort แบบมาตรฐานบนข้อมูล 5 ตัว เปรียบเทียบหาค่าน้อยสุดรวมกี่ครั้ง?

- ก. 5
- ข. 10
- ค. 20
- ง. 25

### ข้อ 14

ข้อมูลเกือบเรียงแล้ว ควรเลือกอะไรในสามอัลกอริทึมพื้นฐานที่เรียน?

- ก. Selection
- ข. Bubble แบบไม่หยุดก่อน
- ค. Insertion
- ง. ทั้งหมดใช้เวลาจริงเท่ากันเสมอ

### ข้อ 15

Stable sort หมายถึงอะไร?

- ก. รักษาลำดับเดิมของรายการที่ key เท่ากัน
- ข. เวลาเป็น O(n) เสมอ
- ค. ไม่ใช้ recursion
- ง. ไม่ใช้หน่วยความจำ

### ข้อ 16

Merge Sort แบบมาตรฐานในบทเรียนมี worst-case time เท่าใด?

- ก. O(1)
- ข. O(n)
- ค. O(n²)
- ง. O(n log n)

### ข้อ 17

Quick Sort เลือกตัวท้ายเป็น pivot เจอข้อมูลเรียงแล้ว อาจเกิดอะไร?

- ก. ไม่มี recursion
- ข. แบ่งเท่ากันเสมอ
- ค. เวลาเป็น O(n²)
- ง. กลายเป็น stable

### ข้อ 18

โค้ดนี้แสดงค่าอะไร?

```python
a = [3, 1, 2]
b = a.sort()
print(b)
```

- ก. `[1,2,3]`
- ข. `None`
- ค. `[3,1,2]`
- ง. Error เสมอ

### ข้อ 19

Hash Table มีข้อมูล 6 รายการ capacity 8 มี load factor เท่าใด?

- ก. 0.75
- ข. 0.25
- ค. 1.33
- ง. 2

### ข้อ 20

ทำไม Linear Probing จึงใช้ Tombstone เมื่อลบข้อมูล?

- ก. เพื่อเรียง key
- ข. เพื่อไม่ให้ collision เกิดอีก
- ค. เพื่อเพิ่ม capacity
- ง. เพื่อให้การค้นหาข้ามช่องที่ถูกลบไปต่อได้
